Put it on your site

You only do this once. After that, just edit here and press Publish.

  1. In Squarespace, open the page and click Edit.
  2. Click + Add Block (or the + in a section) and choose Code.
  3. Delete what's in the box, paste the code below, and make sure Display Source is off.
  4. Click outside the block, then Save. Done — it shows up on the live site. (Squarespace's editor sometimes hides scripts while editing; check the live page.)
